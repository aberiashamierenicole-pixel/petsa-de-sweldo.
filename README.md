# Petsa de Sweldo – Payroll and Attendance Management System

A Java-based payroll and attendance management system using MySQL, designed to simplify employee record management, attendance tracking, payroll processing, and payslip generation.

## Project Overview

Petsa de Sweldo is a database-driven application that provides administrative and employee workflows for managing payroll and attendance operations. It combines a web-based frontend with a Java backend and MySQL database.

## Key Features

- **Employee Management** – Manage employee profiles and account information.
- **Attendance Tracking** – Record and manage employee time-in and time-out entries.
- **Payroll Processing** – Organize payroll periods and calculate employee payroll.
- **Payslip Management** – Generate and access employee payslip information.
- **User Management** – Support different user roles and access.
- **Audit Logs** – Maintain records of important system activities.

## Setup and Installation

1. Clone or download this repository.
2. Install the required JDK and MySQL Server.
3. Download MySQL Connector/J and place the JAR file inside `backend/lib/`.
4. Copy `application.properties.example` and rename the copy to `application.properties`.
5. Configure your local database connection settings.
6. Execute the SQL scripts provided in `backend/sql/` as instructed.
7. Follow the project scripts or README instructions to build and run the backend and frontend.

Refer to the included configuration and scripts for the exact setup commands.
